# Git в VS Code

**Удобно в VS Code:**
1. Наглядный diff с подсветкой изменений.
2. Разрешение конфликтов кнопками (Accept Current/Incoming).
3. Панель Source Control: коммит, ветки, push — в один клик.

**Удобнее в терминале:**
- Интерактивный rebase (`git rebase -i`) — squash, amend, правка истории.
